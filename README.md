# Design and Implementation of an Inventory Tracking and Logistics Management Platform

Project application for a multi-user web platform that centrally manages stock across multiple warehouses.

[Read the project application](00-project/application/00-application.md)

## Proposed scope

- Relational database and hierarchical product categories.
- Product-level and category-level stock monitoring.
- Transactional warehouse transfers with concurrency protection.
- Authentication and role-based access for administrators and warehouse staff.
- Dashboard alerts, statistics, combined filters, and PDF inventory lists.
- Automated verification of business processes and database integrity.
- Installation preparation and documentation for a server environment.

This repository currently contains the project application; implementation has not started.
